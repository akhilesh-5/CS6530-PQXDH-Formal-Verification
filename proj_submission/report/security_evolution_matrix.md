| Security Dimension | Primary Paper [R1] (Signal PQXDH - Bhargavan et al. '24) | Supporting Literature [R2] (Duverger et al. CCS '25) | Supporting Literature [R3] (Abiega-L’Eglisse et al. '26) | Supporting Literature [R4] (Olushola & Meenakshi '26) |
| :--- | :--- | :--- | :--- | :--- |
| **1. Classical to PQ Key Agreement** | Retrofits X3DH by combining 4 classical X25519 DH operations with ML-KEM-1024. | Analyzes subversion-resilient key exchange where KEM randomness or implementations are backdoored. | Designs a clean-slate post-quantum instant messaging protocol without legacy Diffie–Hellman components. | Assembles a standalone post-quantum session protocol integrating ML-KEM-512, ML-DSA-44, and AES-256-GCM. |
| **2. Harvest-Now-Decrypt-Later (HNDL)** | Uses KEM shared secret ($SS$) to shield classical DH against future CRQCs. | Protects against quantum adversaries even under algorithm substitution attacks (ASA). | Implements bidirectional post-quantum ephemeral key ratchets for instant messaging. | Guarantees post-quantum forward secrecy via ephemeral Kyber key generation per session. |
| **3. Protocol & Key Binding** | Identified KEM re-encapsulation flaw; resolved via AEAD Associated Data ($\text{AD} = IK_A \parallel IK_B \parallel PQPK$). | Binds public keys into deterministic transcript hashes before cryptographic reduction. | Cryptographically binds the full message transcript into KDF and key confirmation tags. | Binds client public keys and ciphertexts into a cumulative transcript signed with ML-DSA. |
| **4. Specification vs. Implementation** | Spec omitted key binding; Signal client was safe only because Kyber's FO transform hashed $H(pk)$. | Demonstrates how specification ambiguities allow algorithm substitution during compilation. | Emphasizes strict protocol state machines over informal prose descriptions. | Highlights buffer pre-allocation and constant-time library APIs as critical implementation invariants. |
| **5. Formal Verification Methodology** | ProVerif (symbolic Dolev-Yao) and CryptoVerif (computational game-hopping reductions). | Uses game-based security proofs under algorithm-substitution attacks (ASA). | Verifies secrecy and mutual authentication using automated state-space exploration. | Evaluates empirical cryptographic timing and CPU cycle consumption. |
| **6. Resistance to Key Confusion** | Mitigated by enforcing distinct prefix bytes for X25519 vs. Kyber-1024 public keys. | Requires strict cryptographic domain separation strings across all hash inputs. | Enforces rigid ASN.1 / CBOR schema definitions for all wire-format keys. | Uses fixed-size binary structs with hardcoded protocol header identifiers. |
| **7. Bandwidth & Network Impact** | Adds ~1.5 KB per prekey bundle; acceptable for asynchronous mobile store-and-forward. | Focuses on algorithmic overhead of multi-party subversion-checking protocols. | Analyzes message bloat in mobile messaging networks and battery drain. | Demonstrates that post-quantum digital signatures (Dilithium = 2.4 KB) cause IP packet fragmentation. |
